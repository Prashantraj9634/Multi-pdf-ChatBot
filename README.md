# Multi-PDF AI Chatbot (RAG System)

A clean, production-ready Retrieval-Augmented Generation (RAG) conversational assistant. Upload multiple PDFs and ask natural language questions with automatic source citations (document name + page number) and conversational memory.

Built with **Python**, **LangChain**, **ChromaDB**, **Sentence Transformers**, **Hugging Face**, and **Streamlit**. **100% free of OpenAI fees.**
